# Places to loot

Coordinates are in [`map-spec.md`](map-spec.md#landmarks).

| Place | Loot | What it's for |
|---|---|---|
| **Napa State Hospital** | High-value medical | Main place cave keycards drop. Fenced campus with the Skyline Park hills behind it |
| **Napa County Airport** | Military, helicopter crash sites | Hangars and open runways. Second place keycards drop |
| **Downtown Napa / Oxbow** | City: food, tools, clothing | Dense loot. The river bridges become choke points |
| **Napa River** | n/a | Splits the map in two; crossing it is a decision |
| **Carneros** | Farms, hunting | Open rolling vineyards: sniper country, sparse farmhouses |
| **Hwy 29 / Silverado Trail** | Wineries, gas stations | The two main roads up the valley. Wine Train cars along Hwy 29 as loot spots |
| **Skyline Wilderness Park** | Hunting, camping | Hills and trails east of the hospital |
| **Yountville** | Small town | North edge of the map. Veterans Home campus optional |
| **Wine caves (3–5)** | Best on the map | Keycard only. See [`wine-caves.md`](wine-caves.md) |

## Naming rule

Real places and street names are fine. **Wineries get made-up names** to avoid trademark trouble with real winery brands.
